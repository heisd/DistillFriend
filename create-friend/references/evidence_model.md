# Evidence Model

Use this rubric when extracting or merging friend traits.

## Confidence tiers

### Tier A — direct evidence
- repeated chat patterns
- quoted phrases
- explicit statements from the user
- repeated screenshots / posts showing the same trait

Use for stable claims.

### Tier B — strong inference
- a trait supported by multiple anecdotes but not explicitly stated
- repeated behavioral pattern with small ambiguity

Use with soft language like “usually”, “often”, “tends to”.

### Tier C — weak inference
- single anecdote
- vague vibe-only description
- heavily interpreted screenshot

Keep in uncertainty logs or as optional flavor only.

## Merge rules

- repeated low-stakes behaviors can outweigh one-off statements
- direct user corrections outrank earlier inference
- one funny story does not equal a defining trait
- shared memories matter more than detached biography for friend simulation
- if unsure, leave a blank rather than hallucinating

## Red flags

Do not overstate authenticity when source coverage is thin.
Do not invent trauma, diagnoses, or secret opinions.
Do not turn playful teasing into cruelty unless source material clearly supports it.
