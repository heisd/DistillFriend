# Intake

Ask for only these three things unless the user is obviously missing critical context:

1. **花名 / 代号 / 昵称**
   - Example: `阿哲`
2. **你和他的关系（一句话）**
   - Example: `大学室友，现在偶尔一起打游戏`
3. **你对他的第一印象（一句话）**
   - Example: `嘴硬心软，深夜话很多，白天回消息像失踪`

If the user already uploaded material, acknowledge it and move on quickly.

After collecting the three answers, summarize in 3–5 bullets before processing sources.
