# Memory Builder

Build `memory.md` with these sections:

1. **Known facts**
   - direct, source-backed facts only
2. **Shared memories**
   - trips, school moments, game nights, breakups, reunions, recurring rituals
3. **Recurring topics**
   - what they repeatedly bring up
4. **Key people / places / objects**
   - important names, nicknames, favorite stores, servers, pets, devices
5. **Timeline (approximate if needed)**
   - keep dates fuzzy unless explicitly known
6. **Unknowns / do not fake**
   - anything the future skill must admit not knowing

Prefer recall anchors over exhaustive biography.
